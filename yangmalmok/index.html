양말목이 뭐예요?

양말 공장에서 양말 입구 부분을 동그랗게 잘라내고 남는 고리 모양 자투리 천이에요. 고무줄처럼 늘어나서 서로 걸고, 끼우고, 묶어서 여러 가지를 만들 수 있어요. 버려질 천을 다시 쓰는 재활용 공예예요.

준비물: 색깔별 양말목, 어린이 가위, 키링 고리(선택), 눈알 스티커(선택), 노란 펜(선택)

✂️ 고리를 자르는 단계는 어른이랑 같이 해요. 매듭을 꽉 당길 때 손가락이 끼지 않게 조심!
👀 보는 법 — 그림이 한 단계씩 저절로 움직여요. ⏸ 멈춤을 누르고 ◀ ▶로 한 칸씩 넘겨 봐도 되고, 아래 번호를 누르면 그 단계로 바로 가요.

먼저 배울 기초 기술 4가지

아래 7개 작품은 전부 이 4가지 기술만 섞어서 만들어요. 하나씩 연습해 보고 넘어가요!

A고리 잇기 (사슬)

가장 많이 쓰는 기술! 고리끼리 기차처럼 이어요.
  1. 노랑 고리를 손가락으로 살짝 벌려서 들어요.고리 안에 손가락 두 개를 넣고 양쪽으로 벌리면 구멍이 잘 보여요.
  2. 분홍 고리를 노랑 고리 구멍 안으로 반쯤 쏙 통과시켜요.분홍 고리의 가운데쯤이 노랑 고리에 걸리게 해요.
  3. 분홍 고리를 반으로 접어서, 위쪽 끝 ㉠과 아래쪽 끝 ㉡이 나란히 만나게 해요.노랑 고리에 분홍 고리가 '걸려 있는' 모양이 돼요.
  4. 위쪽 끝 ㉠을 아래쪽 끝 ㉡의 구멍 안으로 쏙 넣어요.헷갈리면: "위에 있는 애가 아래 있는 애 구멍으로 들어간다!"
  5. ㉠을 오른쪽으로 쭉 당기면 노랑 고리 끝에 매듭이 꽉 생겨요.너무 세게 당기면 고리가 작아지니까 '꽉' 할 때까지만 당겨요. 남은 ㉠ 구멍이 다음 고리를 걸 자리예요.
  6. ㉠ 구멍에 다음 색 고리를 넣고 2~5번을 반복하면 기차처럼 길어져요.고리 몇 개를 이었는지 같이 세면서 하면 영상도 재밌어요.

B매듭공 만들기

바퀴, 아이스크림, 구름, 딸기를 만들 때 써요.
  1. 고리 하나를 준비해요.색은 만들 작품에 맞게 골라요. 바퀴는 검정, 구름은 흰색!
  2. 어른이 가위로 고리 한 군데를 싹둑 잘라요.가위는 꼭 어른이랑 같이.
  3. 쭉 펴면 긴 끈 하나가 돼요.양 끝을 잡고 살짝 당기면 끈이 동글동글 말려서 더 튼튼해져요.
  4. 끈 가운데에 동그라미를 만들고, 한쪽 끝을 동그라미 안으로 넣어 매듭 하나.신발 끈 묶을 때 첫 번째 매듭이랑 똑같아요.
  5. 그 매듭 바로 위에 한 번 더, 또 한 번 더 묶어요.매번 같은 자리에 겹쳐 묶어야 동그래져요. 3번 묶으면 작은 공, 5번이면 큰 공!
  6. 동글동글 매듭공 완성! 남은 꼬리 2개는 다른 곳에 묶는 끈이에요.꼬리는 자르지 말고 그대로 두세요. 나중에 몸통에 묶을 때 써요.

C다발 묶어 조이기

여러 개를 하나로 묶을 때! 바나나 꼭지, 문어 목도리에 써요.
  1. 묶을 고리나 사슬들을 한 손에 모아 꽉 쥐어요.높이를 맞춰서 잡으면 완성했을 때 예뻐요.
  2. 다른 색 고리를 다발 뒤쪽에 대요.고리 한쪽 끝을 엄지로 눌러 고정해요.
  3. 고리를 다발에 빙글빙글 두세 바퀴 감아요.감을 때마다 살짝 당기면서 감아야 헐렁해지지 않아요.
  4. 감은 고리 끝을 자기 구멍으로 빼서 꽉 당기면 완성! 묶은 곳 위아래가 퍼지면 성공이에요.힘이 모자라면 마지막 당기기만 어른이 도와줘요.

D동그라미 잇기

사슬을 동그란 링으로! 팔찌, 무지개에 써요.
  1. A 기술로 사슬을 만들어요.팔찌로 쓸 거면 손목에 한 바퀴 둘러보고 길이를 맞춰요.
  2. 사슬을 동그랗게 구부려서 첫 고리와 마지막 고리가 만나게 해요.꼬이지 않게 바닥에 놓고 구부리면 쉬워요.
  3. 마지막 고리를 맨 처음 고리 구멍에 넣고 A 기술처럼 연결해요.A 기술 4~5번처럼 쏙 넣고 꽉 당기면 돼요.
  4. 동그란 링 완성! 팔찌나 바퀴, 장식으로 써요.링 여러 개를 이으면 목걸이도 돼요.

🍌 바나나 송이 키링

난이도 ★☆☆ · 약 15분 · 기술 A + C
노랑 9개 갈색 1개 검정 1개 (선택) 🔑 키링
  1. 노랑 고리 3개를 A 기술로 이어서 바나나 1개를 만들어요.너무 세게 당기면 바나나가 짧아져요. 살살 당겨서 통통하게!
  2. 똑같이 2개 더 만들어서 바나나 3개를 준비해요.3개를 나란히 놓고 길이가 비슷한지 비교해 봐요.
  3. 바나나 3개의 첫 고리(윗부분)를 한 손에 모아 쥐어요.윗부분 높이를 딱 맞춰서 잡아요.
  4. 갈색 고리로 C 기술! 모은 윗부분을 두세 바퀴 감고 꽉 당기면 꼭지 완성.꽉 안 조이면 바나나가 빠져요. 마지막 당기기는 아빠 찬스!
  5. 갈색 고리 남은 구멍에 키링을 끼워요.키링이 없으면 가방 고리에 그대로 걸어도 돼요.
  6. (선택) 검정 끈을 짧게 잘라 바나나 끝마다 작은 매듭을 묶어요.바깥쪽 두 개를 손으로 살짝 바깥으로 휘어주면 송이 느낌이 확 살아요.
🎬 촬영 포인트 — 노란 고리 3개만 먼저 보여주고 "이게 뭐가 될까요?" 퀴즈를 내요. 꼭지를 묶는 순간 정답 공개!

🍌 껍질 반 깐 바나나

난이도 ★★☆ · 약 20분 · 기술 A + C · NEW
아이보리(연노랑) 2개 노랑 3개 갈색 1개 👀 눈알 스티커 (선택)
  1. 아이보리 고리 2개를 A 기술로 이어서 세워요. 껍질 속 하얀 알맹이예요.아이보리가 없으면 흰색이나 연노랑도 OK.
  2. 노랑 고리 3개를 알맹이 아랫부분에 둘러 세워요. 앞에 1개, 양옆에 1개씩.노랑 고리가 알맹이보다 조금 짧아야 위로 알맹이가 쏙 보여요.
  3. 맨 아래를 한꺼번에 모아 갈색 고리로 C 기술 꽉! 남은 갈색은 아래쪽 꼭지(손잡이)가 돼요.제일 중요한 매듭이에요. 알맹이랑 노랑 고리 3개가 전부 같이 묶였는지 확인!
  4. 노랑 고리 3개의 윗부분을 하나씩 바깥쪽 아래로 휙 뒤집어 내려요. 껍질 까기!뒤집은 고리를 손바닥으로 꾹 눌러주면 축 늘어진 껍질 모양이 잘 잡혀요.
  5. 갈색 끈으로 작은 매듭을 만들어 알맹이 꼭대기에 묶으면 완성!눈알 스티커를 붙이고 펜으로 입을 그리면 바나나 캐릭터가 돼요.
💡 응용 — 껍질을 2개만 뒤집고 1개는 세워두면 "까는 중" 바나나가 돼요.
🎬 촬영 포인트 — 바나나 송이랑 나란히 두고 "까기 전 / 깐 후" 비교샷! 껍질을 하나씩 뒤집는 장면은 슬로모션으로 찍으면 좋아요.

🚗 빵빵 꼬마 자동차

난이도 ★★☆ · 약 25분 · 기술 A + B
빨강 4개 하늘 1개 검정 2개 노랑 1개
  1. 빨강 고리 4개를 A 기술로 한 줄로 이어요. 자동차 몸통이에요.몸통은 너무 꽉 당기지 말고 통통하게!
  2. 하늘색 고리 한쪽 끝은 2번째 빨강 고리에, 다른 쪽 끝은 3번째 빨강 고리에 걸어요. 위로 불룩한 창문 지붕!거는 방법은 A 기술이랑 똑같아요. 빨강 고리 구멍에 넣고 자기 구멍으로 빼서 당기기.
  3. 검정 고리 2개로 B 기술 매듭공을 하나씩 만들어요. 바퀴예요.두 바퀴 크기를 맞추려면 매듭 횟수를 똑같이(3번씩) 해요.
  4. 바퀴 꼬리 끈을 1번째, 4번째 빨강 고리 아래쪽에 묶어 달아요.꼬리 끈 2개로 빨강 고리를 감싸고 리본 묶듯 두 번 묶어요. 남은 끈은 짧게 잘라요.
  5. 노랑 고리를 잘라 작은 매듭을 만들고 맨 앞 고리에 묶으면 헤드라이트!뒤쪽에 빨강 작은 매듭을 달면 브레이크등도 돼요.
  6. 완성! 책상 위에서 부릉부릉 끌고 다녀 봐요.색만 바꾸면 경찰차(검정·흰색), 택시(노랑), 소방차(빨강+사다리) 시리즈!
🎬 촬영 포인트 — 마지막에 책상 위에서 "부릉부릉~" 끌고 다니는 장면으로 끝내요. 민국이한테 운전시키는 장면도 딱!

🍦 3단 아이스크림콘

난이도 ★★☆ · 약 20분 · 기술 B + C
베이지 4개 분홍 1개 연두 1개 연노랑 1개 빨강 1개
  1. 베이지 고리 3개를 반으로 접어서 한 다발로 모아요.접힌 쪽이 위로 가게 잡아요.
  2. 다발 맨 아래를 베이지 끈으로 C 기술 꽉 묶어요. 위쪽을 벌리면 콘 모양!묶는 끈은 남은 베이지 고리 1개를 잘라 쓰면 색이 맞아서 예뻐요.
  3. 분홍, 연두, 연노랑 고리로 B 기술 매듭공을 하나씩, 모두 3개 만들어요.스쿱이 콘보다 조금 커야 아이스크림 같아요. 매듭을 4번씩!
  4. 분홍과 연두는 콘 윗부분 양쪽에, 연노랑은 그 위 가운데에 꼬리 끈으로 묶어요.꼬리 끈을 콘 고리 사이로 넣어 뒤에서 묶으면 매듭이 안 보여요.
  5. 빨강으로 작은 매듭공을 만들어 꼭대기에 묶으면 체리 완성!스쿱 색을 바꿔서 "민지 맛 / 민국이 맛 / 아빠 맛" 놀이도 해봐요.
🎬 촬영 포인트 — "무슨 맛 먹을래요?" 하고 댓글로 맛을 고르게 하면 다음 편 소재가 생겨요.

🐙 꼬물꼬물 문어 친구

난이도 ★★☆ · 약 20분 · 기술 C (+ 가위)
보라 4개 분홍 1개 👀 눈알 스티커 2개
  1. 보라 고리 4개를 겹쳐 쥐고 반으로 접어요. 접힌 쪽이 머리 꼭대기예요.4개 높이를 맞춰서 잡아요.
  2. 접힌 쪽 끝에서 손가락 두 마디쯤 아래를 분홍 고리로 C 기술 꽉 묶어요. 위는 동그란 머리, 분홍은 목도리!묶은 다음 머리를 손으로 동글동글 매만져서 모양을 잡아요.
  3. 아래로 늘어진 고리 끝을 어른이 가위로 잘라요. 고리 4개가 끈 8가닥, 다리 8개가 돼요!문어 다리는 진짜로 8개예요. 같이 세어 봐요.
  4. 다리 끝마다 매듭을 하나씩 묶어요. 꼬물꼬물 다리 완성.매듭 위치를 조금씩 다르게 하면 다리가 춤추는 것 같아요.
  5. 눈알 스티커를 붙이고 웃는 입을 그려주면 완성!색만 바꾸면 해파리(하늘색, 다리 길게), 오징어(흰색)도 돼요.
🎬 촬영 포인트 — 가위로 자르는 순간 고리가 다리로 "짠" 변하는 게 하이라이트! 클로즈업으로 찍어요.

🌈 구름 무지개 장식

난이도 ★★★ · 약 30분 · 기술 A + B
빨강 5개 주황 4개 노랑 3개 초록 2개 파랑 1개 흰색 4개
  1. A 기술로 색깔별 사슬을 만들어요. 빨강 5개, 주황 4개, 노랑 3개, 초록 2개, 파랑 1개!길이가 계단처럼 하나씩 짧아져요. 파랑은 고리 1개 그대로예요.
  2. 긴 것부터 짧은 것 순서로 바깥에서 안쪽으로 무지개 모양으로 겹쳐 놓아요.바닥에 놓고 모양부터 잡으면 쉬워요.
  3. 흰 고리로 매듭공을 만들어요. 2개는 왼쪽 구름, 2개는 오른쪽 구름!매듭공 2개를 꼬리 끈끼리 묶으면 뭉게구름이 돼요.
  4. 왼쪽 구름의 꼬리 끈으로 5줄 사슬의 왼쪽 끝을 한꺼번에 묶어요.5줄 끝을 빨래집게로 잠깐 집어두면 묶기 쉬워요.
  5. 오른쪽 구름으로 오른쪽 끝도 묶어요. 무지개가 둥글게 휘어요!무지개 모양이 비뚤면 사슬을 살짝 당겨서 맞춰요.
  6. 남은 끈으로 걸이 고리를 만들어 꼭대기에 달고 벽이나 창가에 걸어요.처음엔 빨·노·파 3색만 작게 만들어 연습해도 좋아요.
🎬 촬영 포인트 — "빨! 주! 노! 초! 파!" 색깔을 외치면서 이어가면 리듬감 있는 영상이 돼요. 마지막에 창가에 걸면서 마무리!

🍓 통통 딸기 키링

난이도 ★☆☆ · 약 15분 · 기술 B + C
빨강 2개 초록 1개 🖊️ 노란 펜 🔑 키링
  1. 빨강 고리 2개를 준비해요.고리가 클수록 딸기도 커져요.
  2. 어른이 두 고리를 각각 잘라 끈으로 만들고, 끝끼리 묶어서 긴 끈 하나로 이어요.이은 매듭은 나중에 딸기 속에 숨겨져서 안 보여요.
  3. 긴 끈으로 B 기술 매듭을 4~5번 겹쳐 묶어 크고 통통한 공을 만들어요.매번 같은 자리에 겹쳐 묶어야 동그래져요.
  4. 공을 손으로 꾹꾹 눌러서 아래가 뾰족한 딸기 모양으로 다듬어요.아래쪽을 손가락으로 살짝 집어 주면 뾰족해져요.
  5. 초록 고리를 딸기 윗부분에 C 기술로 감아 묶고, 양쪽으로 벌려 꼭지 잎을 만들어요.남은 꼬리 끈도 이용해서 함께 감으면 튼튼해요.
  6. 초록 고리 남은 구멍에 키링을 끼워요.키링 대신 끈을 달면 가방 장식이 돼요.
  7. 노란 펜으로 콕콕 점을 찍으면 딸기 씨 완성!같은 방법으로 귤(주황+초록 잎), 체리(빨강 작은 공 2개)도 만들 수 있어요.
