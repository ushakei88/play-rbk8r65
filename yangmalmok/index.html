양말목이 뭐예요?

양말 공장에서 양말 입구 부분을 동그랗게 잘라내고 남는 고리 모양 자투리예요. 늘어나는 동그란 고무줄 같은 천이라, 서로 걸고 끼우고 묶어서 냄비받침·꽃·팔찌·키링 같은 걸 만들 수 있어요. 버려질 천을 다시 쓰는 재활용 공예라서 이야기거리도 좋아요.

준비물: 색깔별 양말목, 어린이 가위, 키링 고리(선택), 눈알 스티커(선택)

✂️ 고리를 자르는 단계는 어른이랑 같이 해요. 매듭을 꽉 당길 때는 손가락이 끼지 않게 조심!

먼저 배울 기초 기술 4가지

아래 6개 작품은 전부 이 4가지 기술만 섞어서 만들어요.

A고리 잇기 (사슬)

  1. 고리 ①을 펼쳐 들어요.
  2. 고리 ②를 ① 구멍에 반쯤 통과시켜요.
  3. ② 한쪽 끝을 ② 자기 구멍으로 쏙 빼서 당기면 연결 끝!
  4. 반복하면 기차처럼 길게 이어져요.

B매듭공 만들기

  1. 고리 하나를 가위로 한 번 잘라 긴 끈으로 만들어요. (어른 도움)
  2. 가운데에 매듭을 하나 지어요.
  3. 그 매듭 위에 한 번, 또 한 번 더 묶으면 동글동글 공이 돼요.
  4. 남은 꼬리 2개는 다른 곳에 묶는 끈으로 써요.

C다발 묶어 조이기

  1. 여러 고리나 사슬을 한 다발로 모아 잡아요.
  2. 다른 색 고리를 다발에 두세 바퀴 감아요.
  3. 감은 고리 끝을 자기 구멍으로 빼서 꽉 당겨 조여요.

D동그라미 잇기

  1. A 기술로 사슬을 만들어요.
  2. 마지막 고리를 맨 처음 고리 구멍에 넣어 똑같이 연결해요.
  3. 그럼 동그란 링 완성! 팔찌·바퀴·무지개에 써요.

🍌 바나나 송이 키링

난이도 ★☆☆ · 약 15분 · 기술 A + C
노랑 9개 갈색 1개 검정 1개 (선택) 🔑 키링 고리
  1. 노랑 고리 3개를 A 기술로 이어서 바나나 1개를 만들어요.
  2. 똑같이 2개 더 만들어 바나나 3개를 준비해요.
  3. 3개의 윗부분(첫 고리)을 한 손에 모아 쥐어요.
  4. 갈색 고리로 C 기술, 모은 윗부분을 꽉 감아 묶으면 꼭지 완성.
  5. 갈색 고리 남은 구멍에 키링을 끼워요.
  6. (선택) 검정 끈을 짧게 잘라 바나나 끝마다 매듭 하나씩 → 진짜 바나나 끝처럼!
💡 모양 잡기 — 바깥쪽 두 개를 살짝 바깥으로 휘어지게 손으로 눌러주면 송이 느낌이 확 살아요.
🎬 촬영 포인트 — 처음엔 노란 고리 3개만 보여주고 "이게 뭐가 될까요?" 퀴즈 → 꼭지 묶는 순간 공개!

🚗 빵빵 꼬마 자동차

난이도 ★★☆ · 약 25분 · 기술 A + B
빨강 4개 하늘 1개 검정 2개 노랑 1개
  1. 빨강 고리 4개를 A 기술로 한 줄로 이어요. 이게 자동차 몸통이에요.
  2. 하늘색 고리 한쪽을 2번째 빨강 고리에, 다른 쪽을 3번째 빨강 고리에 걸어 묶어요. 위로 불룩 솟은 창문 지붕이 돼요.
  3. 검정 고리 2개로 각각 B 기술 매듭공을 만들어요. 이게 바퀴!
  4. 바퀴 꼬리 끈을 1번째, 4번째 빨강 고리 아래쪽에 묶어 달아요.
  5. 노랑 고리를 잘라 작은 매듭 하나 → 맨 앞 고리에 묶으면 헤드라이트.
  6. 남은 꼬리는 짧게 잘라 정리해요.
💡 업그레이드 — 색만 바꾸면 경찰차(검정+흰색, 지붕에 빨강·파랑 매듭), 택시(노랑) 시리즈로 만들 수 있어요.
🎬 촬영 포인트 — 완성 후 책상 위에서 "부릉부릉~" 끌고 다니는 장면으로 마무리. 민국이한테 운전시키기 장면도 딱!

🍦 3단 아이스크림콘

난이도 ★★☆ · 약 20분 · 기술 B + C
베이지/갈색 3개 분홍 1개 연두 1개 연노랑 1개 빨강 1개
  1. 베이지 고리 3개를 반으로 접어 한 다발로 모아요.
  2. 다발 맨 아래를 베이지 고리 한쪽 끈으로 C 기술 묶기 → 위로 벌어지는 콘 모양이 돼요.
  3. 분홍·연두·연노랑 고리로 각각 B 기술 매듭공 3개를 만들어요. 이게 아이스크림 3스쿱!
  4. 분홍과 연두는 콘 윗부분 양쪽에, 연노랑은 그 위 가운데에 꼬리 끈으로 묶어요.
  5. 빨강으로 작은 매듭공 → 맨 꼭대기에 묶으면 체리 완성.
💡 맛 바꾸기 — 스쿱 색을 바꿔서 "민지 맛 / 민국이 맛 / 아빠 맛" 아이스크림 만들기 놀이도 돼요.
🎬 촬영 포인트 — "무슨 맛 먹을래요?" 하고 시청자에게 댓글로 맛 고르게 하면 다음 편 소재가 생겨요.

🐙 꼬물꼬물 문어 친구

난이도 ★★☆ · 약 20분 · 기술 C (+ 가위)
보라 4개 분홍 1개 👀 눈알 스티커 2개
  1. 보라 고리 4개를 겹쳐서 반으로 접어요. 접힌 쪽이 머리 꼭대기예요.
  2. 접힌 쪽 끝에서 손가락 두 마디쯤 아래를 분홍 고리로 C 기술 꽉 묶어요. 위쪽 동그란 부분이 머리, 분홍은 목도리!
  3. 아래로 늘어진 고리 끝을 어른이 가위로 잘라주면 끈이 8가닥이 돼요.
  4. 8가닥 끝마다 매듭을 하나씩 지어요. 꼬물꼬물 다리 완성.
  5. 머리에 눈알 스티커를 붙이면 끝!
💡 시리즈로 — 색을 바꾸면 해파리(하늘색, 다리를 길게), 오징어(흰색, 머리를 세모로 눌러 묶기)도 같은 방법으로 돼요.
🎬 촬영 포인트 — 가위로 자르는 순간 고리가 다리로 "짠" 변하는 게 하이라이트. 클로즈업 추천!

🌈 구름 무지개 장식

난이도 ★★★ · 약 30분 · 기술 A + B
빨강 5개 주황 4개 노랑 3개 초록 2개 파랑 1개 흰색 4개
  1. A 기술로 색깔별 사슬을 만들어요. 빨강 5개, 주황 4개, 노랑 3개, 초록 2개, 파랑 1개 — 길이가 계단처럼 달라져요.
  2. 긴 것부터 짧은 것 순서로 바깥→안쪽에 무지개 모양으로 겹쳐 놓아요.
  3. 흰 고리 2개를 각각 B 기술 매듭공으로 → 왼쪽 구름, 2개 더 → 오른쪽 구름.
  4. 왼쪽 구름 꼬리 끈으로 5줄 사슬의 왼쪽 끝을 한꺼번에 묶어요.
  5. 오른쪽 구름으로 오른쪽 끝도 똑같이 묶으면 무지개가 둥글게 휘어요.
  6. 남은 끈으로 고리를 만들어 벽이나 가방에 걸어요.
💡 난이도 낮추기 — 처음엔 빨·노·파 3색만, 사슬 3·2·1개로 작게 만들어 보세요.
🎬 촬영 포인트 — 빨주노초파 색깔을 하나씩 외치면서 이어가면 리듬감 있는 영상이 돼요. 마지막에 창가에 걸어서 마무리!

🍓 통통 딸기 키링

난이도 ★☆☆ · 약 15분 · 기술 B + C
빨강 2개 초록 1개 노란 펜 또는 노랑 1개 🔑 키링 고리
  1. 빨강 고리 2개를 잘라 끝끼리 묶어 긴 끈 하나로 만들어요.
  2. 긴 끈으로 B 기술 매듭을 4~5번 겹쳐 묶으면 크고 통통한 공이 돼요.
  3. 공을 손으로 살짝 눌러 아래가 뾰족한 딸기 모양으로 다듬어요.
  4. 초록 고리를 딸기 윗부분에 C 기술로 감아 묶어요. 양쪽으로 벌리면 꼭지 잎!
  5. 초록 고리 남은 구멍에 키링을 끼워요.
  6. 노란 펜으로 콕콕 점을 찍거나, 노랑 끈을 아주 짧게 잘라 끼우면 딸기 씨.
💡 과일가게 시리즈 — 같은 방법으로 귤(주황 공+초록 잎), 체리(빨강 작은 공 2개+초록 줄기), 포도(보라 작은 공 여러 개)까지!
🎬 촬영 포인트 — 바나나 키링이랑 딸기 키링을 같이 들고 "민지네 과일가게 오픈!" 컨셉으로 묶어 올리면 시리즈가 돼요.

🎥 "민 지금 뭐해" 양말목 시리즈 제안

  1. 1편 양말목이 뭐게? + 바나나 송이 (제일 쉬움, 첫 편으로 딱)
  2. 2편 통통 딸기 → "민지네 과일가게" 시작
  3. 3편 꼬물꼬물 문어 (자르는 순간 반전)
  4. 4편 빵빵 자동차 + 민국이 운전 장면
  5. 5편 3단 아이스크림 — 댓글로 맛 고르기
  6. 6편 구름 무지개 — 시즌 마무리 장식
